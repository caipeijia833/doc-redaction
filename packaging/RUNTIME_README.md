# 智能文档脱敏系统 Alpha（离线运行包）

## Windows 启动

1. 完整解压本压缩包，不要在压缩软件预览窗口中运行。
2. 双击 `start-windows.bat`。
3. 启动器会先执行完全离线的环境和组件校验；浏览器未自动打开时，访问命令窗口显示的 `DOC_REDACTION_URL`。
4. 首次验证只使用 `samples` 目录内的合成样例。
5. 保持命令窗口开启；关闭窗口或按 `Ctrl+C` 停止本地服务。

Windows 运行包包含裁剪后的 Java 21、便携 Tesseract 5.5.2 及 `chi_sim`/`eng`/`osd` 数据、LGPL-only FFmpeg、whisper.cpp、多种 CPU/OpenCV 视觉检测，以及 Qwen3-VL-2B-Instruct Q4_K_M。它不要求另装 Java、Python、数据库或在线模型，也不修改系统 PATH、注册表或服务；Vulkan 加速需要机器已有兼容显卡驱动，无兼容显卡时自动回退 CPU。

环境预检会检查 Windows 版本/架构、物理内存、可用磁盘、数据目录写权限以及 `app/runtime/ocr/media/vlm/update` 全量文件 SHA-256，并实际探测 Java、Tesseract、FFmpeg、whisper.cpp、OpenCV JNI 和 llama.cpp。组件缺失、被修改或出现额外文件时，只从包内 `repair/components.zip` 恢复；修复归档自身也先校验 SHA-256。按资源自动选择 constrained、balanced、standard 档位。少于 4 GiB 内存、少于 4 GiB 可用磁盘、架构不匹配或组件无法运行时会安全阻断，报告位于 `data/diagnostics/environment-report.json`。该过程不联网、不请求管理员权限，也不能补充物理内存或磁盘。

## macOS 启动

macOS 专用运行包中执行：

```bash
chmod +x start-macos.command
./start-macos.command
```

Windows 包不能用于 macOS。macOS Intel 与 Apple Silicon 包必须在对应平台生成，并另行完成签名、公证和实机验收。

## 当前功能

- DOCX：正文、表格、页眉页脚、脚注、尾注、批注和部分元数据。
- XLSX：字符串单元格、批注、页眉页脚和部分元数据；公式保持不变并对风险报警。
- PPTX：普通文本框、表格、备注、母版/版式及图表缓存文字；位图需要本地 OCR；OLE、ActiveX、VBA 和签名部件失败关闭。
- PDF：文本坐标或本地 OCR 定位后栅格化重建，不保留原文本层。
- OFD：隔离进程逐页渲染、本地 OCR 遮挡并按原页物理宽高重建栅格 OFD；已通过 OFDRW 上游 3 个 Apache-2.0 文字、JPEG、签章实样的渲染解码回归；原签章失效，必须重新签章。
- PNG/JPG/JPEG/BMP：本地 OCR 坐标遮挡并重新编码。
- MP3/WAV/M4A/FLAC：全部音轨本地 ASR，规则命中时间段静音，重新编码并清除元数据。
- MP4/MOV/MKV：音轨 ASR、文本字幕脱敏、位图/未知字幕移除；画面文字、人脸、二维码和中国车牌按时间坐标烧录遮挡。
- ZIP、TAR、TAR.GZ、7Z：先显示内容清单再处理；RAR 只识别反馈。
- 未支持文件默认排除；只有再次确认后才能原样保留，危险文件和不安全路径永远排除。
- 处理前人工复核、任务级忽略、脱敏后格式文本残留复扫。
- 新建任务采用五步向导：选择/拖放文件并本地预检、设置项目与模式、按任务选择规则并预览输出文件名、确认风险、查看处理进度与下载结果；确认前不会自动开始处理。
- 文件名主体使用与正文相同的任务规则范围进行脱敏并保留扩展名；同项目重名自动追加序号。压缩包内部文件与目录路径同步脱敏，清单记录原路径与输出路径；还原加密原件时恢复上传时的原文件名。
- 自建本地预览：Office 文本预览、PDF/OFD/图片栅格预览、音视频 Range 流式播放及命中时间跳转；未集成 kkFileView 或 WPS 在线预览。
- 205 条内置中英文及国际规则，包含 44,712 项中国大陆省级、地市级、区县级、乡镇/街道级离线行政区划词典，并覆盖身份、地理地址、金融、医疗、教育、就业、网络设备、司法、房产、车辆等类别；支持规则启停、黑白名单、自定义规则新增/编辑/复制/删除、样例测试、JSON 导入导出和 20 版历史回滚。
- 可逆模式使用 AES-256-GCM 加密原件并要求二次确认口令；正确口令恢复上传时的原始字节并校验 SHA-256。结果文件上的遮挡或静音本身不可逆。
- 浏览器多选/拖放、逐文件格式和大小反馈、项目 UUID、历史项目分组/搜索/分页、任务或整项目删除、命中统计、处理报告和结果下载。
- 单文件接收上限 1 GiB，上传逐块写盘并计算 SHA-256。
- 默认仅运行一个文档工作进程，可通过系统属性调整为 1–2 个；默认单并发用于降低大文件同时解析造成的内存与磁盘峰值。
- 正式 Windows 启动强制把工作进程树放入 Job Object，设置关闭即终止、32 个活动进程和按机器档位选择的提交内存上限，并在任务历史中记录峰值内存/磁盘；这仍不等于文件或网络权限沙箱。

## 离线升级与回滚

`update` 目录包含签名更新应用和回滚脚本。更新清单必须通过 Ed25519 公钥、逐文件 SHA-256、大小、完整集合和数据架构版本校验；运行中的应用会被单实例锁阻断升级。`data` 目录不会进入更新包，也不会被替换。当前可信公钥模板为空，发布者未配置公钥前所有更新都会被拒绝；不要把私钥放入运行包。

## 数据位置

任务记录位于运行包的 `data/projects`，规则配置和本机化名主密钥位于 `data/config`。

- 等待人工复核或压缩包确认时，任务明文暂存在任务目录。
- 任务完成或失败后，程序清理其任务明文副本。
- 可逆模式保留 `vault/original.drenc` 加密原件，口令不会写入配置或历史。
- 项目名、文件名、压缩包内部路径、历史记录及用户保存的黑白名单仍可能敏感，应保护整个 `data` 目录。

## 严格限制

本版本只用于合成数据和功能验证，不能直接作为真实卷宗外发系统。以下能力尚未实现或通过验收：

- Windows 包已捆绑并验证 Tesseract 5.5.2 与中英文训练数据；32 条合成精确规则金标已纳入自动回归，但它不能替代真实业务数据；真实低清、旋转、表格、手写体及复杂版面语料的召回率尚未验收；
- 音视频第一阶段只通过合成语音、画面文字、文本字幕及官方/生成视觉样例；真实噪声、口音、多人重叠、快速运动、多国车牌、长视频和 1 GiB 媒体尚未验收；默认最长音频 4 小时、视频 30 分钟，视频最多抽取 900 帧；
- 当前音频处理方式是命中时间段静音，不支持变声或敏感词替音；视频已对相邻采样帧做保守轨迹桥接，但无法发现两次采样之间完整出现又消失的快速闪现，外发前必须人工检查完整时间轴；
- SmartArt、宏、自定义 XML、全部嵌入对象等复杂 Office 内容的完整处置；
- 企业级密钥托管、角色权限、双人审批和完整审计链；
- 精确 1 GiB PDF 与近上限 1 GiB 高密度 DOCX/XLSX/PPTX 已在 Windows 本机合成语料上完成；这不等于复杂对象或真实业务 1 GiB 文档验收；10,000 文件批次、暂停恢复和断点续传仍未验收；
- macOS 13 Intel/Apple Silicon 实机验收；
- Windows/macOS 安装包签名、公证及生产安全验收。
- 当前 BtbN FFmpeg 二进制的完整对应源代码闭包尚未完成独立核验；在 `FFMPEG_SOURCE_CLOSURE.json` 标记完成前，不得把本运行包作为公开 GitHub Release 发布。

`SHA256SUMS.txt` 记录包内各文件的 SHA-256，可用于整体完整性复核；`repair/COMPONENTS_SHA256SUMS.txt` 是启动时关键组件基准。启动器和预检脚本仍依赖发布包本身可信，正式发布前必须补代码签名/公证和可信下载哈希。
