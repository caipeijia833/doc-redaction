# 用户操作指南（简体中文）

## 1. 启动与语言

Windows x64 用户解压完整离线包后运行 `start-windows.bat`；macOS 13+ 用户在已验收的对应架构包中运行 `start-macos.command`。启动预检只检查和修复包内组件，不联网安装、不提权，也不修改系统 PATH、注册表或服务。

浏览器打开命令窗口显示的 `DOC_REDACTION_URL`，通常为 `http://127.0.0.1:8765/`。右上角可切换简体中文与 English。不要把该地址改成局域网地址或通过反向代理公开。

## 2. 五步新建脱敏任务

1. **选择文件**：点击或拖放多个文件。单文件上限 1 GiB；页面会先检查扩展名和大小，不会立即处理。
2. **项目与模式**：同一批文件进入同一项目。不可逆模式在处理完成后清理任务明文副本；可还原模式额外保存 AES-GCM 加密原件，要求设置至少 10 个字符的项目口令。
3. **规则与文件名**：选择规则分类，可启用处理前人工复核。正文、普通文件名和压缩包内部路径使用同一规则范围，扩展名保留，重名自动编号。
4. **确认风险**：核对文件、输出名、规则和还原策略，勾选确认后才开始上传和本地处理。
5. **处理与下载**：查看逐文件状态；完成后下载结果。需要人工复核或压缩包确认的任务会暂停，完成确认后继续。

## 3. 压缩包

第一阶段支持 ZIP、TAR、TAR.GZ 和 7Z。RAR 只识别并提示，不解压、不处理。系统先生成安全清单：可脱敏文件进入处理；不支持文件默认排除，只有用户二次确认后才可原样放入结果包。不要原样保留来源不明的可执行文件、脚本或带宏文档。

## 4. 历史项目与还原中心

“历史项目”按项目查看状态、命中数、时间、下载、重试和删除能力。“还原中心”只显示本机数据库中的任务：仅创建时选择“可还原”且加密原件仍存在的任务可还原。输入原口令后，本机服务解密、校验原文件 SHA-256 并下载原件；口令不保存。忘记口令或删除加密原件后无法恢复。

脱敏结果本身不可逆：PDF/OFD/图片采用重建或遮挡，音视频重新编码或静音，不能通过“移除遮罩”还原。

## 5. 规则库

规则库包含内置规则、自定义规则、黑名单、白名单和版本历史五个标签页。自定义规则使用 RE2/J 兼容正则；先用合成文本测试，再保存。规则、黑白名单每次变更都会形成本地版本。回滚前先导出当前自定义规则；回滚不会替代数据目录备份。

## 6. 使用边界

- 姓名、单位、自然语言地址和图像目标存在误报/漏报，正式材料必须人工复核。
- 加密 PDF、损坏文件、极端复杂排版、罕见 OFD、噪声音频和快速运动视频可能失败或降级。
- 1 GiB 代表上传上限及已验证的部分合成路径，不保证任意真实 1 GiB 文件都能在给定时间/内存内完成。
- 处理前保留原文件离线备份；先在副本上验证结果，再用于业务流转。

故障排查见 [TROUBLESHOOTING.md](./TROUBLESHOOTING.md)，备份与卸载见 [BACKUP_RESTORE_UNINSTALL.md](./BACKUP_RESTORE_UNINSTALL.md)。
