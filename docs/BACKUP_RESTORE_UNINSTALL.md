# Backup, data recovery, and uninstall / 备份、数据恢复与卸载

## Data boundary / 数据边界

运行包的 `data` 目录包含历史任务、项目名、原文件名、规则配置、诊断信息，以及可还原模式的加密原件。整个目录都应视为敏感数据。还原口令不保存在数据目录；没有口令无法解密加密原件。

## Backup / 备份

1. 等待所有任务结束，关闭浏览器并退出启动窗口，确认程序不再运行。
2. 将整个 `data` 目录复制到加密、访问受控的离线介质，不要只复制数据库文件。
3. 记录应用版本、`DATA_SCHEMA_VERSION` 和备份 SHA-256；将口令通过独立渠道保管。
4. 在隔离副本上定期验证能启动、能查看历史，并用合成任务验证还原；不要用唯一真实原件做演练。

运行中热拷贝可能造成 SQLite、任务目录和加密原件不一致，不受支持。

## Recover after reinstall / 重装后恢复

只在相同数据架构版本或有明确迁移说明的版本之间恢复。关闭程序，保留新安装自动创建的空 `data`，再用完整备份替换该目录；启动后先检查诊断、历史数量和规则版本，再用合成任务验证。任何迁移失败都应回退到原程序副本和原数据备份，不要反复覆盖唯一备份。

## Uninstall / 卸载

程序不注册系统服务，不需要修改 PATH 或注册表。退出程序后，可移走或删除解压目录完成卸载。若需要保留历史、规则或可还原原件，必须先备份 `data`。删除 `data`、遗失口令或遗失加密原件后不可恢复。浏览器下载目录中的脱敏结果和已还原原件不随程序卸载自动删除，应按本单位数据制度另行处理。

## Secure disposal / 安全处置

普通文件删除不保证在所有 SSD、备份软件或快照中物理清除。高敏数据的介质处置应使用操作系统或设备支持的加密擦除/销毁流程，并同时处理备份、同步盘、下载目录和系统快照。
