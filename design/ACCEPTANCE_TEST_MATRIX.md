# 初步验收矩阵

以下是PoC和正式版本的验收目标，不代表当前已经通过。

## 当前 Alpha 证据摘要（2026-08-14）

| 已有证据 | 当前结论 |
|---|---|
| Windows 中文路径源码构建、62 项自动化测试、包内 JRE/OCR/媒体组件启动及本地 API 冒烟 | 通过本机合成样例验证；未等同于目标机生产验收 |
| 启动环境预检、资源档位、关键组件全量 SHA-256、故意篡改后的包内离线恢复 | Windows x64 本机通过；macOS 脚本未实机验证 |
| DOCX/XLSX/PPTX/文本型 PDF 小文件生成、脱敏、重开与残留复扫 | 通过基础合成样例验证；不覆盖全部复杂对象 |
| ZIP/TAR/TAR.GZ/7Z 分项处理；未支持文件默认排除与二次确认；RAR 反馈 | 通过自动化测试，ZIP 另通过浏览器流程验证 |
| AES-GCM 原件加密、正确口令恢复及 SHA-256 一致；错误口令失败 | 通过自动化测试；尚无企业权限/密钥托管 |
| OFD 合成文件生成与预览、Tesseract 5.5.2 中英文合成图识别遮挡、OCR 缺失失败关闭 | 通过自动化测试；真实中文 OFD/OCR 金标仍未验收 |
| 中英文界面切换、浏览器偏好保持、205 条规则英文名、人工复核、移动端布局 | 通过最终 Windows 包浏览器闭环；日志/审计/原文不翻译 |
| 精确 1 GiB PDF 处理；精确 1 GiB TAR 接收与清单确认 | Windows 本机通过；不等同于所有格式或真实业务卷宗通过 |
| 高密度 Office 阶梯 | 256 MiB、512 MiB、近上限 1 GiB DOCX/XLSX/PPTX 均在 2 GiB 工作堆下通过处理、全量残留复扫与结构检查 |
| 音视频第一阶段 | 合成中英文数字语音静音、视频 OCR 遮挡、文本字幕重封装、残留复扫、一次性子进程，以及人脸/二维码/中国车牌样例通过 |
| macOS、10,000 文件实压、真实音视频金标、长视频/1 GiB 媒体、完全断网抓包 | 未验证 |

## 平台与离线

| 编号 | 场景 | 验收条件 |
|---|---|---|
| ENV-01 | Windows 10/11中文用户目录 | 中文路径、空格、长文件名下可安装、启动、处理和导出 |
| ENV-02 | macOS 13+ Intel | 安装包可启动，处理结果与Windows规则一致 |
| ENV-03 | macOS 13+ Apple Silicon | 原生或明确标注的兼容运行，无静默功能降级 |
| ENV-04 | 完全断网 | 阻断全部出站连接后，除在线更新外的核心功能全部可用 |
| ENV-05 | 模型/组件缺失或损坏 | 优先从校验通过的包内修复副本恢复；修复失败则明确阻断，不得联网下载 |
| ENV-06 | 资源不足 | 自动降低堆、并发、ASR 线程和抽帧上限；低于硬门槛时生成报告并阻断，不得声称能补充物理资源 |

## 文件规模与批量

| 编号 | 场景 | 验收条件 |
|---|---|---|
| CAP-01 | 正常1GB文件接收 | 流式写盘，不发生整文件内存复制，SHA-256正确 |
| CAP-02 | 1GB PDF/视频处理 | 可分片、显示进度、暂停恢复，失败不损坏原件 |
| CAP-03 | 大型OOXML | 解包额度内完成；超出安全额度时可解释地拒绝 |
| CAP-04 | 10,000文件批次 | 分页展示、可恢复、单文件失败不终止整个项目 |
| CAP-05 | 压缩炸弹/路径穿越 | 在写出工作目录前拦截，不覆盖目录外文件 |

## 格式保真

| 编号 | 场景 | 验收条件 |
|---|---|---|
| FMT-01 | DOCX复杂样式 | Word和LibreOffice均可打开；段落、表格、页眉页脚和分页无不可接受漂移 |
| FMT-02 | XLSX公式与隐藏内容 | 可打开；公式、格式保留；隐藏表和外链按策略处理 |
| FMT-03 | PPTX母版与备注 | 可打开；母版、备注、隐藏页均经过扫描 |
| FMT-04 | PDF文本型 | 被脱敏内容无法复制、搜索或从对象流恢复 |
| FMT-05 | PDF扫描型 | 遮挡区域与OCR坐标一致，旋转页和倾斜页无明显偏移 |
| FMT-06 | OFD | 主流阅读器可打开；签章失效状态被明确记录 |
| FMT-07 | 音频 | 所有音轨都经过 ASR；命中区间在重新编码结果中不可听；元数据无原敏感值；输出可正常播放 |
| FMT-08 | 视频 | 音轨、字幕和画面均按策略处置；遮挡已烧录进新视频；音画同步、时长、分辨率与播放器兼容满足阈值 |

## 识别质量

| 编号 | 场景 | 初步目标 |
|---|---|---|
| DET-01 | 带校验位的身份证、银行卡、统一社会信用代码 | 合成规范语料召回率100%，误报率低于0.5% |
| DET-02 | 手机、邮箱、IP、案号等结构化规则 | 合成及边界语料召回率不低于99.5% |
| DET-03 | 中文姓名、地址、组织机构 | 在经确认的法律卷宗测试集上，机器建议召回率不低于95%；外发模式仍须人工复核 |
| DET-04 | 图片中文OCR | 按清晰扫描、低分辨率、旋转、印章覆盖分别统计，不以总体平均值掩盖弱项 |
| DET-05 | 跨文档一致替换 | 同项目同实体映射一致，不同项目默认不可关联 |
| DET-06 | 中英文音频 ASR | 按清晰/噪声/口音/多人重叠/数字读法分别统计；外发语料中敏感片段召回目标不低于 99%，低置信度必须人工复核 |
| DET-07 | 视频文字/人脸/车牌/二维码 | 按静止、快速移动、遮挡、压缩噪声、光照和国家分别统计；不得用抽帧样例通过替代完整时间轴召回率 |

## 安全与还原

| 编号 | 场景 | 验收条件 |
|---|---|---|
| SEC-01 | 残留扫描 | 对抗测试语料中，外发结果不存在可恢复的原敏感文本、批注、附件或元数据 |
| SEC-02 | 还原权限 | 未授权角色不能获取映射或还原原文 |
| SEC-03 | 字节级恢复 | 加密原件恢复后SHA-256与导入时一致 |
| SEC-04 | 日志泄漏 | 日志、错误栈、临时清单不包含敏感原值或密钥 |
| SEC-05 | 解析器崩溃 | 子进程被终止，主服务继续运行并记录原因 |
| SEC-06 | 项目删除 | 删除策略覆盖数据库、文件、映射和备份，并明确SSD普通删除的局限 |

## 接口与审计

| 编号 | 场景 | 验收条件 |
|---|---|---|
| API-01 | 重复提交 | 幂等键相同时不会产生重复处理任务 |
| API-02 | 中断续传 | 1GB文件传输中断后可安全继续或重新开始 |
| API-03 | 审计链 | 导入、规则变更、复核、导出、还原均记录人员、时间、版本和文件哈希 |
| API-04 | 规则版本 | 历史项目可以重现当时使用的规则和模型版本 |

## 验收证据要求

- 每个测试保留输入文件哈希、环境版本、规则版本、输出哈希和机器资源数据。
- 使用合成或授权脱敏样本，不把真实敏感卷宗提交到公开缺陷系统。
- 通过与未通过必须分开报告；没有在目标操作系统上运行的项目不得标记为通过。
