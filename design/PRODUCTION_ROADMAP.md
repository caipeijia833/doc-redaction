# 单机离线正式版建设路线

更新时间：2026-08-13

## P0：可靠运行底座

已落地：

- SQLite 持久任务索引、WAL、状态审计和原有属性文件迁移。
- 项目 UUID、10,000 项持久队列、启动恢复、项目分组/搜索/分页、取消、中断重试、任务与整项目永久删除。
- 20 GiB 默认数据配额、2 GiB 最低空闲空间和并发磁盘预留。
- 文档/压缩包/复核/预览全部进入一次性受限子 JVM。
- 子进程内存上限、超时和取消终止。
- OFD/图片/Tesseract 适配代码及失败关闭策略。
- CycloneDX SBOM、依赖锁和构件 SHA-256 验证。
- DOCX/XLSX/PPTX 包级事件流改写、单语义单元有界缓冲和全量输出残留复扫。
- 2 GiB 工作堆下近上限 1 GiB 高密度 DOCX/XLSX/PPTX 合成阶梯。

尚未达到 P0 验收：

- 在带 `chi_sim` 的 Windows 与 macOS 上跑通真实扫描 PDF、OFD、图片和 Office 内嵌图片。
- 真实复杂对象的 1 GiB DOCX/XLSX/PPTX、1 GiB OFD，以及内存、I/O、临时磁盘的连续峰值监测。
- 10,000 项压缩包、8 GiB 展开量、断电/强杀/磁盘写满恢复测试。
- 子进程操作系统级沙箱、原生 OCR 进程资源限制和畸形文件模糊测试。

## P1：格式与卷宗质量

1. 建立脱敏金标集：身份证、姓名、地址、案号、联系方式、银行信息、机构名，以及横排/竖排/印章覆盖/低清扫描。
2. 给每种格式设定“召回率、误报率、版式差异、处理耗时、峰值内存”验收阈值。
3. 扩充 OOXML 真实对象语料：SmartArt、隐藏工作表、修订和矢量对象；图表缓存/关系/自定义属性已进入包级处理，OLE/ActiveX/VBA/签名当前失败关闭。
4. OFD 增加真实签章、附件、字体、透明层和异常包测试；输出明确标记“需重新签章”。
5. 在现有 XLSX 包级事件流基础上验证真实百万行、多工作表、共享字符串、公式和图表的兼容性与性能。
6. 建立项目级清单、失败项重试、导出报告和可核验的处理证据链。

## P2：音视频与低算力视觉能力

第一阶段低算力闭环已落地：

- 固定哈希的 LGPL-only FFmpeg 共享运行时，本地解封装、重新编码和元数据清理；
- whisper.cpp 多语言 CPU ASR，对全部音轨按规则命中时间段静音；
- 文本字幕重写，位图字幕和未知轨道失败关闭式移除；
- 抽帧 OCR、YuNet 人脸、WeChatQRCode 二维码和中国车牌检测，按时间与坐标烧录遮挡；
- 本地 Range 预览、时间点跳转、逐项忽略和输出残留复扫；
- FFmpeg、ASR、OCR 或视觉模型缺失时拒绝接收媒体任务。

P2 仍未达到正式验收，下一步按以下顺序完成：

1. 建立中英文真实语音金标集，按噪声、口音、多人重叠、数字读法和编码格式分别量化召回率。
2. 增加跨帧目标跟踪、场景切换感知与短暂闪现检测，避免只靠固定间隔抽帧漏掉快速出现的内容。
3. 扩展美国、欧盟、英国、日本、韩国等车牌检测，并补身份证件、屏幕文字和条码的真实视频语料。
4. 对 30 分钟上限、4 小时音频、1 GiB 媒体、取消、磁盘写满和 120 分钟工作进程超时做压力验收。
5. 增加可调模糊/马赛克、声码器变声或敏感片段替音；当前仅提供不可逆遮挡和静音。
6. 量化画面采样降级警告，并要求外发前人工检查完整时间轴。

在这些验收完成前，只能表述为“音视频第一阶段支持”，不能表述为真实业务零漏检或生产验收完成。

## P3：原生安装与发布工程

- Windows：在 Windows 构建 `exe/msi`，使用 WiX，完成代码签名、安装/卸载、升级、中文路径和普通用户权限测试。
- macOS：分别在 Intel 与 Apple Silicon 构建 `pkg/dmg`，完成 Developer ID 签名、公证、Gatekeeper、macOS 13+ 和 NFC/NFD 中文路径测试。
- 每个平台发布物包含 SHA-256、CycloneDX SBOM、第三方许可证、离线安装说明和回滚说明。
- `jpackage` 不支持跨平台产包，因此 Windows 与 macOS 必须在各自目标系统构建。依据：[Oracle jpackage 文档](https://docs.oracle.com/en/java/javase/21/jpackage/basic-packaging.html)。

## P4：企业多用户版（后置）

- RBAC/ABAC、SSO、租户隔离、双人审批、集中 KMS/HSM、密钥轮换。
- 不可抵赖审计、保留策略、法务封存、数据分级和外发审批。
- REST/消息队列/文件交换接口，以及幂等、回调签名、限流和错误重放。
- 高可用数据库、对象存储、任务调度与水平扩展。SQLite WAL 明确只适合单机同主机边界，不作为企业集群数据库。
