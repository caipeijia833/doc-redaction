# 合成音视频验收样例

Windows 运行包在本目录附带三个完全合成的本地验收文件；它们不来自真实案件、个人或业务数据。

| 文件 | 合成内容 | 预期结果 | SHA-256 |
|---|---|---|---|
| `sensitive-phone-slow.wav` | Windows 系统 TTS 朗读虚构手机号 `13800138000` | ASR 命中后对应时间段静音，输出残留复扫为 0 | `3993c01d781c6b75db0f4e9a126eb9fe6fc6e289bfc472e5f1cfa01c659b43c5` |
| `sensitive-visual.mp4` | 白底画面显示 `Mobile Phone 13800138000`，无音轨 | OCR 命中手机号并生成不可逆黑色遮挡 | `b2e90433ca6955e8c7e68c0d2c900e076b5e0134949bd5a6b9c8f33ae1357bf7` |
| `sensitive-subtitle.mp4` | 空白合成视频，MOV_TEXT 字幕包含虚构手机号，容器注释也含该值 | 文本字幕脱敏后重新封装，容器元数据清除 | `a55e9f1b9d89acb1aa1d3c817f14fcd864bd3122b91cb04fccc48fd5d567b462` |

建议勾选“处理前人工复核”，检查音频时间段、视频坐标和字幕时间段能否跳转到本地播放器。样例只证明固定测试链路，不代表真实口音、噪声、低清画面、快速运动和多国车牌召回率。
