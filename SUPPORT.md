# Support / 支持范围

This is a community-maintained single-machine offline Alpha. There is no guaranteed response time or production SLA.

- Use a GitHub Issue for reproducible bugs and feature requests after the repository is public.
- Use GitHub Private Vulnerability Reporting for security defects.
- Never upload real case files, unredacted personal information, passwords, keys, tokens, restore ciphertext, or raw local logs.
- Include version, operating system, architecture, synthetic reproduction steps, expected behavior, actual behavior, and tests already attempted.

Windows x64 is the currently verified development platform. macOS 13 Intel and Apple Silicon scripts exist but remain unverified until real-machine acceptance is completed.
