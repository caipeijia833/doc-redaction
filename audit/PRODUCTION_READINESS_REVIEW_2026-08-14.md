# 上线准备度代码审查（2026-08-14）

审查对象：`doc-redaction` 单机离线 Alpha，版本 `0.1.0-poc`。
审查范围：业务逻辑、边界条件、自动化测试、依赖与秘密风险、Windows 构建、浏览器端到端流程、README 与许可证说明。
不在范围：GitHub 初始化、提交、推送、公开发布、Codex for OSS 申请；本轮均未执行。

## 1. 最终结论

**结论：可用于受控的单机内部试用，不可宣称已具备正式生产上线条件。**

本轮已消除多项可直接利用或导致脱敏遗漏的高、中风险问题，83 项自动化测试及本机浏览器合成样例端到端均通过。阻止正式上线的主要因素已不再是基本 CRUD 或页面流程，而是解析进程缺少操作系统权限沙箱、OpenCV 桌面原生依赖老化、macOS 双架构无实机证据、真实业务金标语料/恶意样本/更新签名体系不足，以及本轮 PDF 改为逐页 OCR 后尚未重新执行 1 GiB 压力回归。

## 2. 本轮修复

| 编号 | 风险 | 处置与验证 |
|---|---|---|
| R-01 | DNS rebinding 可用伪造 Host 读取首页会话令牌 | 所有请求在路由前校验 `localhost`、`127.0.0.1`、`[::1]` 及实际端口；原始 Socket 伪造 Host 回归返回 421，响应不含令牌 |
| R-02 | 被篡改的 `job.properties` 可把明文清理路径指向数据目录外 | 加载时拒绝符号链接目录/状态文件，要求任务 ID 与目录一致，输入/输出/加密库路径分别位于固定子目录；恶意状态回归被跳过且外部文件保留 |
| R-03 | 任务目录或状态临时文件可被预创建/链接劫持 | 新任务只接受安全 ID 并使用 `createDirectory` 创建全新目录；状态使用随机 `CREATE_NEW` 临时文件和原子替换 |
| R-04 | 批量还原中途失败仍提前增加部分任务的还原次数 | 全部加密原件完成解密、SHA-256 校验并生成 ZIP 后才提交审计计数；不同口令双文件回归确认失败时两项计数均为 0 |
| R-05 | ZIP/7Z 只依赖声明大小，未知或错误元数据可绕过累计展开量限制 | 新增实际读取字节累计器；单条目 1 GiB、累计处理量 8 GiB 双限制，溢出失败关闭；增加累计与长整型溢出测试 |
| R-06 | 压缩倍率使用整数除法，`200.x` 倍可能漏判 | 改为商与余数比较，避免边界漏判和乘法溢出 |
| R-07 | 用户自定义 Java 正则仍可能产生灾难性回溯 | 自定义规则改用 RE2/J 1.8 线性时间引擎；内置规则保留经审查的 JDK 正则；长输入回归在时限内完成，环视/反向引用失败关闭 |
| R-08 | PDF 仅检查页面直接图片对象，嵌套 Form/其他绘制路径可能漏过 OCR | 先按文本坐标遮挡，再对每个已渲染页面执行本地 Tesseract 视觉复核；缺 OCR 时 PDF 整体失败关闭 |
| R-09 | Office 非敏感外部关系仍可能在打开结果时联网 | 所有 `TargetMode=External` 目标替换为 `about:blank`；XML 外部实体解析器显式抛错；非敏感跟踪 URL 回归通过 |
| R-10 | Windows 保留设备名和 Unicode 截断可能导致落盘失败/半个代理项 | 统一文件名工具处理 CON/PRN/AUX/NUL/CLOCK$/COM1-9/LPT1-9，按 Unicode 码点截断；文件名与压缩包目录共用 |
| R-11 | 加密写入发生 I/O 错误时可能留下部分 vault | `IOException` 与密码学异常均清理未完成的加密文件；口令及派生密钥继续在 finally 中清零 |
| R-12 | 主密钥 POSIX 权限依赖 umask | 在支持 POSIX 权限的平台将配置目录设为 0700、密钥设为 0600；Windows 继续使用用户目录继承 ACL |
| R-13 | 传递依赖包含已知漏洞版本 | Log4j API 2.24.3 覆盖为 2.25.5；OFD worker 的 `org.json:20141113` 覆盖为 20260719；依赖锁与构件 SHA-256 元数据已更新 |
| R-14 | 向导结束页次按钮被主按钮挤压换行 | 限定向导按钮 flex 与 `white-space`；浏览器截图复核按钮为单行 110×44 px |

## 5. 上线分级建议

- **允许**：隔离测试机、合成/已去标识数据、人工逐份复核、结果不直接外发的单机试用。
- **有条件允许**：低风险内部材料，前提是受控账户、全盘加密、断网、人工抽检、保留原件备份并接受格式边界。
- **不允许**：未经人工复核的司法卷宗自动外发；高保密原件；公网/局域网多人服务；宣称覆盖所有国家证件或所有音视频场景；macOS 正式分发。
