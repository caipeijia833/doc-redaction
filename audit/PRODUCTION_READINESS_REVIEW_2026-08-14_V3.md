## 1. 本轮完成的代码与数据能力

### 1.1 中国大陆优先规则库

- 内置规则由 77 条扩展为 205 条，中英文界面均有名称。
- 新增 44,712 项中国大陆行政区划离线词典，按省级、地市级、区县级、乡镇/街道级输出独立规则命中；使用层级和地址上下文抑制同名普通词误报。
- 进一步补齐居民身份、职业资格、医疗、教育、就业、金融税务、支付账号、网络设备、凭证、司法卷宗、房产、车辆、公用事业、经纬度、邮编、网址、IPv4/IPv6、MAC 等规则及校验器。
- 行政区划来源固定为 2023 年公开快照，生成脚本校验源文件哈希；这不是实时民政区划库。源项目已说明 2024 年 10 月后不再提供最新统计区划代码，因此正式使用前必须建立年度更新和差异审核流程。

### 1.2 公开样本与金标边界

- 已核验并捆绑 OFDRW 上游 3 个 Apache-2.0 实样：文字、JPEG、签章 OFD；它们只用于格式兼容测试，不是敏感信息金标。
- 测试发现 OFDRW 转换器在排除 iText 后仍会触发字体加载引用。已使用 OFDRW 自身 Apache-2.0 字体解析能力实现隔离 Worker 内的无 iText `FontLoader`，3 个实样现均可渲染和解码。
- CAIL2018、XFUND、FUNSD、PaddleOCR、Common Voice 等仅登记为链接候选，不随包分发：其任务标签不是脱敏金标，或存在非商业/不允许再托管/隐私等限制，不能把“公开可下载”误写成“可自由再分发的脱敏金标”。
- 新增 32 条完全合成的中国大陆精确规则金标，29 个应命中项全部命中：TP=29、FP=0、FN=0、精确率=1.0、召回率=1.0；门槛分别为 0.99、0.995。该结果只证明确定性规则回归，不能代表 OCR、ASR、视频或真实卷宗准确率。

## 4. 建议准确率门槛

这些数值是进入人工验收的建议门槛，不是当前所有链路已经达到的成绩：

| 能力 | 建议最低门槛 | 附加硬约束 |
|---|---:|---|
| 强结构化规则 | P ≥ 99%，R ≥ 99.5% | 身份证、银行卡等关键号码残留必须为 0 |
| 上下文实体规则 | P ≥ 98%，R ≥ 97% | 分省份、城市、区县、街道及同名歧义分层报告 |
| 清晰印刷体 OCR | P ≥ 95%，R ≥ 95% | 关键 PII 残留复扫为 0；低置信度进入人工复核 |
| 低清/旋转/手写 OCR | R ≥ 90% 后方可试点 | 必须人工逐页复核，不得自动外发 |
| 音频 ASR 脱敏 | 敏感片段召回率 ≥ 95% | 静音边界覆盖完整敏感发音，完整时间轴抽检 |
| 视频画面脱敏 | P ≥ 95%，R ≥ 98% | 关键 PII 残留为 0；快速闪现和采样间隙人工复核 |

## 5. 仍然阻断正式上线

### 5.1 必须由项目所有者提供或执行

1. 获得有合法处理权限的真实法律卷宗、OCR、OFD、音频和视频样本，在本地建立双人标注金标；公开数据不能替代这个步骤。
2. 在代表性 Windows 机器和 macOS 13+ 目标架构实机/虚拟机执行验收；Windows 结果不能证明 macOS、Apple Silicon 或 Intel 包可运行。
3. 决定支持的目标架构，持有并管理 Authenticode、Apple Developer ID、公证凭证和离线更新 Ed25519 私钥；私钥不得放入仓库或运行包。
4. 明确真实原件的保存期、还原授权、密钥托管、备份销毁、审计留存和事故响应规则。
5. 安排独立安全测试，覆盖恶意 Office/PDF/OFD/压缩包、资源耗尽、还原密钥、本机 Web 面和数据目录权限。

### 5.2 开发侧后续可继续完成

1. 在得到合法真实样本后，将金标导入现有评测格式并生成分类、格式、噪声等级和行政区划层级的分桶指标。
2. 增加 Windows AppContainer/独立低权限账户或等价强隔离；现有 Job Object 只做进程生命周期和资源约束，不是文件/网络沙箱。
3. 完成 10,000 文件、多层压缩、磁盘耗尽、中断恢复、1 GiB 长媒体、可变帧率、多音轨和快速闪现耐久性测试。
4. 用真实复杂 OFD 补充嵌入字体、矢量、附件、多尺寸、签章失效和主流阅读器矩阵。
5. 经用户另行授权后再处理 GitHub CI、仓库策略和公开发布；本轮未执行任何 Git 初始化、提交、推送、建仓或申请操作。
