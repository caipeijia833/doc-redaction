02

设置项目与处理模式

同批文件归入同一项目；可还原模式会额外加密保存上传原件。

原件还原说明系统保存加密原件并在还原时校验上传哈希；忘记口令后无法恢复。遮挡或静音后的结果文件本身不能逆向还原。
03

选择本任务规则

默认选中当前启用的全部规则分类。黑名单始终参与检测，文件名与正文使用同一规则范围。
